## 📌 १. मुख्य उद्दिष्ट आणि सिस्टीम आर्किटेक्चर (System Architecture)
Billing On Hand हे भारतीय किरकोळ आणि घाऊक व्यापाऱ्यांसाठी (Retailers & Wholesalers) बनवलेले **१००% ऑफलाइन-फर्स्ट, सुरक्षित आणि आधुनिक GST ERP व बिलिंग सॉफ्टवेअर** आहे.

## 📋 २. सद्यस्थिती आणि पूर्ण झालेली वैशिष्ट्ये (Completed Features - 100%)

### ✅ अ. विक्री आणि खरेदी बिलिंग (Sales & Invoicing - `InvoicingView.tsx`)
- [x] **कॅश, बँक आणि उधारी (Unpaid/Credit) बिलिंग:** ग्राहकानुसार पेमेंट पर्याय.
- [x] **मल्टि-आइटम बिलिंग आणि बारकोड स्कॅनिंग:** त्वरित बारकोड स्कॅनर सपोर्ट.
- [x] **जीएसटी कर रचना (GST Slabs):** CGST, SGST आणि आंतरराज्य IGST (0%, 5%, 12%, 18%, 28%) स्वयंचलित गणना.
- [x] **अतिरिक्त शुल्क (Extra Charges):** ट्रान्सपोर्ट, डिलिव्हरी, पॅकिंग किंवा लेबर चार्जेस बिलामध्ये जोडणे.
- [x] **सेल रिटर्न आणि परतावा (Credit & Debit Notes):** मूळ बिलाचा संदर्भ ठेवून माल परतावा नोंद.
- [x] **एआय इनव्हॉइस स्कॅनर (AI OCR):** कागदी बिल किंवा पीडीएफ फोटो स्कॅन करून थेट कॉम्प्युटरमध्ये नोंद करणे.
- [x] **व्हॉट्सअ‍ॅप शेअरिंग आणि प्रिंट:** थर्मल (58mm/80mm) व A4/A5 बिल प्रिंटिंग व थेट व्हॉट्सअ‍ॅप मेसेज.

### ✅ ब. कोटेशन आणि अंदाजपत्रक (Quotations & Estimates - `QuotationsView.tsx`)
- [x] **कोटेशन निर्मिती व व्यवस्थापन:** Draft, Sent, Accepted आणि Rejected स्टेट्स ट्रॅकिंग.
- [x] **१-क्लिक कन्व्हर्ट टू इनव्हॉइस:** ग्राहक कोटेशन मान्य करतोच १-क्लिकमध्ये त्याचे थेट पक्क्या बिलात रूपांतर.
- [x] **कोटेशन प्रिंट टेम्पलेट (`QuotationPrintModal.tsx`):** कंपनी लोगो, जीएसटी आणि अटी-शर्तींसह प्रिंट.

### ✅ क. डिलिव्हरी चलान (Delivery Challans - `DeliveryChallansView.tsx`)
- [x] **चलान व्यवस्थापन:** वाहन क्रमांक (Vehicle No), ट्रान्सपोर्टर, ई-वे बिल क्रमांक आणि डिलिव्हरी ठिकाण.
- [x] **चलान ते बिल रूपांतर:** माल पोहोचल्यानंतर चलानचे थेट विक्री बिलामध्ये रूपांतर.
- [x] **चलान प्रिंट (`ChallanPrintModal.tsx`):** वाहतूक आणि गेट पाससाठी कायदेशीर चलान फॉरमॅट.

---

### ✅ ड. स्टॉक आणि इन्व्हेंटरी (Inventory & Stock - `ItemsView.tsx`)
- [x] **लाईव्ह स्टॉक ट्रॅकिंग:** खरेदी व विक्री झाल्यावर स्टॉक आपोआप कमी/जास्त होणे.
- [x] **किमान स्टॉक अलर्ट (Low Stock Alerts):** माल संपत आल्यास लाल रंगात धोक्याची सूचना.
- [x] **एआय मल्टि-आइटम स्कॅनर (`ItemsScanModal.tsx`):** अनेक वस्तूंचे फोटो स्कॅन करून एकदम स्टॉक तयार करणे.
- [x] **बारकोड लेबल्स:** उत्पादनांसाठी बारकोड जनरेटर व प्रिंटिंग.

### ✅ इ. ग्राहक व सप्लायर खातेवही (Parties & Khata - `PartiesView.tsx`)
- [x] **ग्राहक व सप्लायर प्रोफाईल:** GSTIN, पत्ता, पॅन कार्ड आणि फोन नंबर व्यवस्थापन.
- [x] **उधारी खातेवही (Khata Ledger):** कोणती पार्टी किती देणे/घेणे बाकी आहे याचे अचूक रेकॉर्ड.
- [x] **पेमेंट रिमाइंडर्स:** व्हॉट्सअ‍ॅपवरून एका क्लिकवर थकबाकी वसुलीचा संदेश पाठवणे.

- [x] **दैनिक खर्च ट्रॅकर:** वीज बिल, दुकानाचे भाडे, कर्मचाऱ्यांचा पगार, चहा-नाश्ता, पेट्रोल इत्यादी खर्चांची नोंद.

- [x] **GSTR-3B रिपोर्ट:** इनपुट टॅक्स क्रेडिट (ITC) आणि एकूण कर दायित्व.
- [x] **नफा-तोटा पत्रक (Profit & Loss):** ग्रॉस प्रॉफिट, नेट प्रॉफिट आणि ऑपरेटिंग खर्च.
- [x] **डे बुक आणि स्टॉक व्हॅल्युएशन:** रोजची आवक-जावक व गोदामातील मालाचे मूल्य.

### ✅ ज. सेटिंग्ज आणि सुरक्षा (Settings & Safeguards - `SettingsView.tsx`)
- [x] **मल्टि-बिझनेस प्रोफाईल:** एकाच सॉफ्टवेअरमध्ये अनेक दुकाने किंवा कंपन्या चालवणे.
- [x] **गुगल ड्राइव्ह ऑटो-बॅकअप:** इंटरनेट सुरू होताच क्लाउडवर स्वयंचलित सुरक्षित बॅकअप.
- [x] **फॅक्टरी हार्ड रिसेट (Wipe All Data):** कन्फर्मेशन आणि सेफगार्डसह डेटाबेस स्वच्छ करण्याची सोय.
- [x] **व्हाईट स्क्रीन प्रतिबंध (Error Boundary & Resilient Recovery):** कोणतीही तांत्रिक अडचण आल्यास सॉफ्टवेअर क्रॅश न होता आपोआप रिकव्हर होण्याची सुरक्षा.

### ✅ झ. डिजिटल मुनीमजी व्हॉइस असिस्टंट (AI Voice Assistant - `MunimjiDrawer.tsx`)
- [x] **युनिफॉईड मराठी/हिंदी/इंग्रजी पुरुष आवाज (Unified Male Voice):** मॉडेल किंवा एपीआय की बदलली तरी आवाज बदलत नाही.
- [x] **व्हॉइस कमांड्सद्वारे बिझनेस ऑपरेशन्स:** "५०० रुपयांचे बिल बनवा", "रमेशचे खाते दाखवा", "स्टॉक तपासा" अशा आज्ञांवर थेट काम.
- [x] **मल्टि-की पूल रोटेशन:** जेमिनीच्या अनेक कीज स्वयंचलित रोटेट करून अखंडित सेवा.

### ✅ ञ. बॅच नंबर आणि एक्सपायरी डेट व्यवस्थापन (Phase 4: Batch & Expiry Tracking - `ItemsView.tsx` & `InvoicingView.tsx`)
- [x] **बॅच क्रमांक व निर्मिती दिनांक (Batch No & Mfg Date):** फार्मसी, किराणा, बियाणे व FMCG साठी अचूक बॅच नोंद.
- [x] **मुदत समाप्ती ट्रॅकिंग (Expiry Date Tracking):** पुढील ४५ दिवसांत मुदत संपणारा (Near Expiry) आणि मुदत संपलेला (Expired) माल त्वरित ओळखणे.
- [x] **इन्व्हेंटरी फिल्टर टॅब्स व अलर्ट्स:** ऑल आयटम्स, कमी साठा, एक्सपायरी अलर्ट्स आणि एक्सपायर्ड स्टॉक स्वतंत्र वर्गवारी.
- [x] **बिलावर बॅच व एक्सपायरी प्रिंट:** थर्मल आणि A4/A5 पावत्यांवर बॅच क्र. आणि एक्सपायरी तारीख आपोआप प्रिंट होणे.
- [x] **मुनीमजी एआय सिंक आणि ऑटो-मिनिमाइज:** "कोणता माल एक्सपायर होत आहे?", "एक्सपायरी स्टॉक दाखवा" अशा व्हॉइस कमांड्सवर थेट उत्तर आणि नेव्हिगेशन होताच मुनीमजी ड्रॉवर ऑटो-मिनिमाइज होणे.

## 🛡️ ४. व्हाईट स्क्रीन आणि डेस्कटॉप सुरक्षा खात्री (Zero White-Screen & Desktop Stability)
1. **React Error Boundary:** कोणत्याही अनपेक्षित UI त्रुटीवेळी संपूर्ण पांढरी स्क्रीन न येता रिकव्हरी पॅनेल उघडते.
2. **Resilient Local Database Sync:** सर्व्हर तात्पुरता व्यस्त असल्यास सॉफ्टवेअर आपोआप ५ वेळा री-ट्राय करते.
3. **Pre-Hydration Fallback:** ॲप्लिकेशन सुरू होताना बॅकएंडशी जोडणी होईपर्यंत सुरक्षित लोडर कार्यान्वित राहतो.
